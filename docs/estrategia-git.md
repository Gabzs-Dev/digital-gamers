# Estratégia Git – Digital Gamers

## Estratégia adotada

Foi escolhido o Trunk-Based Development simplificado para organizar o desenvolvimento do Digital Gamers.

## Organização

- main: branch principal e estável.
- feature/catalogo-produtos: desenvolvimento do catálogo.
- feature/carrinho: desenvolvimento do carrinho.
- feature/filtros: desenvolvimento dos filtros.
- feature/finalizacao: desenvolvimento da finalização simulada.

## Fluxo de trabalho

1. Criar uma branch a partir da main.
2. Desenvolver uma funcionalidade específica.
3. Realizar commits seguindo Conventional Commits.
4. Executar testes e verificar a compilação.
5. Enviar a branch para o GitHub.
6. Criar um Pull Request.
7. Revisar as alterações.
8. Integrar as alterações à main após aprovação.

## Objetivo

Manter a branch principal organizada, facilitar a colaboração e reduzir o risco de incorporar alterações com erros.
